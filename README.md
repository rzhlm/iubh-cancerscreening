# Description
This is the exam project for DLBDSME01 Model Engineering.
The purpose is to build models for breast cancer classification.
The models need to be interpretable and should have an F1-score above 0.95

# Data
The data is the UCI Machine Learning Repository’s Breast Cancer Wisconsin (Diagnostic) dataset (Wolberg, Mangasarian, N. Street, and W. Street, 1993) (https://doi.org/10.24432/C5DW2B)
It contains 569 cases with 30 features derived from fine-needle aspirate images.
It is licensed under Creative Commons Attribution 4.0 International (CC BY 4.0).
